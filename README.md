## 记录方法

学习过程按这个流程走，重点是后两步：

```
学  →  记  →  改  →  比  →  上传  →  沉淀
              ↑         ↑
          容易停下   真正有价值
```

**每节的记录模板**（写在对应 notebook 里）：

```markdown
### YYYY-MM-DD · 第 X.X 节 标题

**学了什么**（3 行说清）
-

**关键代码**


**踩的坑**
- 现象：
- 原因：
- 解决：

**我想试的**
-
```

其中「**踩的坑**」最重要——它记录的是真实遇到的问题，复习和面试时都用得上，而这些细节在教材里找不到。

**改造实验**单独放在 `实验/` 下，格式如 `2026-09-21_adam_vs_sgd/`，包含代码和一张对比结果表。

## 环境

| 项目 | 版本 / 说明 |
| --- | --- |
| Python | 3.12（miniconda3） |
| PyTorch | 见 `requirements.txt` |
| Jupyter | Notebook 7.x |
| 系统 | Windows |

**一键启动学习环境**：双击 `启动Jupyter.bat`，自动切到本目录并打开 Jupyter Notebook。

**一键上传学习记录**：双击 `上传学习记录.bat`，自动 `add → commit → push`。
脚本会自动检测网络：直连 GitHub 不通时，自动切到本地代理。

```bash
# 手动操作时（GitHub 直连不通的情况下）
set HTTPS_PROXY=http://127.0.0.1:65532
git add -A
git commit -m "学习记录：第 2.3 节 线性代数"
git push
```
