### 2. 第 2 章数学：降级细则

原文已声明数学要求不高，所以「降级」不等于「放弃」——**证明可跳，结论不可跳**。

| 小节 | 处理方式 |
|---|---|
| 2.1 数据操作 | **不能跳**，每天都在用 |
| 2.2 数据预处理 | **不能跳**，`Dataset` / `DataLoader` 做实验必用 |
| 2.3 线性代数 | 只保留：张量基本性质、降维（`sum`）、点积、矩阵-向量积、矩阵-矩阵乘法、范数（2.3.10 粗看）。标量/向量/矩阵的「定义」部分快翻 |
| 2.4 微积分 | 只需要两条结论：**梯度 = 偏导数组成的向量**；**链式法则使反向传播可行**。不手推，2.4.6 练习直接跳 |
| 2.5 自动微分 | **必学** |
| 2.6 概率 | 只留期望与方差（Dropout 会用到），其余快翻 |
| 2.7 查阅文档 | 10 分钟读完，纯工具 |

### 3. 裁缝最短路线

```
第2章（精读 2.1 / 2.2 / 2.5）
  → 第3章（抄熟训练循环，以后所有实验的模板）
    → 第4章（消融素材库 + 过拟合/正则化概念）
      → 第5章 ★（裁缝核心，放慢速度，动手改几次）
          → 第8/9章（RNN/LSTM/GRU，序列建模直觉）
            → 第10章 ★（注意力 / Transformer，影视文本的地基，慢下来）
              → 第14/15章（词嵌入 + 预训练，读完立刻转 HuggingFace）
                → 接一个 HuggingFace 中文预训练基准（BERT 系），跑通 = 第一个真实实验
（第6/7章 CNN、第13章 CV：留到课题涉及视频-文本多模态时再回头。）
```

走到**第 5 章末尾**就可以开始「裁」了；**第 10 章 + HuggingFace 跑通后，进入真正的课题裁缝**。

### 4. 里程碑自检

- [ ] 不依赖 d2l 封装，能自己写完整训练循环
- [ ] 能把别人的模块（如某个注意力变体）贴进自己的模型并跑通
- [ ] 能独立设计一组消融（改 / 不改 / 加正则化）
- [ ] 能说清每个超参在干什么，而不是瞎调

## 建议的学习节奏

| 阶段 | 章节 | 目标 |
