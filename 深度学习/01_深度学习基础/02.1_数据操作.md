# 2.1 数据操作

**一句话**：深度学习里所有数据都是**张量**（n 维数组），这一节讲怎么创建、变形、拼接、运算。

---

## 一、切片语法（我最初的速记）

```
用【】表示前行后列，逗号分隔
：表示区间，不加数字表示都要，左闭右开
双冒号表示每 x 一跳
```

**展开成完整规则**：

```
obj[start : stop : step]
```

| 部分 | 含义 | 默认值 |
|---|---|---|
| `start` | 起始（**包含**） | 0（正步长）/ -1（负步长） |
| `stop` | 结束（**不包含**） | 到末尾 |
| `step` | 步长，负数表示倒序 | 1 |

```python
a = [0, 1, 2, 3, 4, 5]

a[1:4]      # [1, 2, 3]      含头不含尾
a[:3]       # [0, 1, 2]      省略 start
a[3:]       # [3, 4, 5]      省略 stop
a[:]        # 全部
a[::2]      # [0, 2, 4]      每 2 跳一步
a[::-1]     # [5,4,3,2,1,0]  倒序
```

**索引示意图**

```
正向:   0    1    2    3    4    5
值:     0    1    2    3    4    5
负向:  -6   -5   -4   -3   -2   -1
```

**多维张量里逗号分隔各维**：

```python
X = torch.arange(12).reshape(3, 4)
X[1, 2]      # 第 1 行第 2 列
X[1, :]      # 第 1 行
X[:, 1]      # 第 1 列
X[0:2, :]    # 前两行
```

> **越界不报错**（切片的特性）：`a[2:100]` 返回 `[2,3,4,5]`，`a[100:]` 返回 `[]`。
> 但**单元素索引越界会报 `IndexError`**：`a[100]` ❌。

## 三、`reshape`：形状的乘积必须等于元素总数

```python
torch.arange(12).reshape((3, 4))   # ✅ 3×4 = 12
torch.arange(12).reshape((2, 4))   # ❌ 2×4 = 8 ≠ 12
```

```
RuntimeError: shape '[2, 4]' is invalid for input of size 12
```

| 写法 | 乘积 | 结果 |
|---|---|---|
| `torch.arange(12).reshape(3, 4)` | 12 | ✅ |
| `torch.arange(12).reshape(2, 6)` | 12 | ✅ |
| `torch.arange(12).reshape(2, 4)` | 8 | ❌ |
| `torch.arange(8).reshape(2, 4)` | 8 | ✅ |

**规律**：各维相乘 **必须等于**元素总数，多一个少一个都不行。

> 和 `reshape` 容易混的是**聚合操作**（如 `sum`）：
> `reshape` **元素数不变**，只是重排；`sum` **元素数变少**，真的做了加法。

## 四、`torch.cat`：只有拼接的那一维可以不同

```python
X = torch.arange(12, dtype=torch.float32).reshape((3, 4))
Y = torch.tensor([[2.0, 1, 4, 3], [1, 2, 3, 4], [4, 3, 2, 1]])   # (3, 4)

torch.cat((X, Y), dim=0)   # (6, 4)  行数相加
torch.cat((X, Y), dim=1)   # (3, 8)  列数相加
```

**核心规则**：**除了拼接维度，其余所有维度必须严格相等。**

反例：

```python
X = torch.arange(12, dtype=torch.float32).reshape((2, 6))        # (2, 6)
Y = torch.tensor([[2.0, 1, 4, 3], [1, 2, 3, 4], [4, 3, 2, 1]])   # (3, 4)
torch.cat((X, Y), dim=0)   # ❌ 第 1 维 6 vs 4
```

```
RuntimeError: Sizes of tensors must match except in dimension 0.
Expected size 6 but got size 4 for tensor number 1 in the list.
```

| 方向 | 要求 | X(3,4) + Y(3,4) |
|---|---|---|
| `dim=0` | 第 1 维必须相同 | (6, 4) |
| `dim=1` | 第 0 维必须相同 | (3, 8) |

> 我原来的速记「**cat 是合并，dim=0 按行，dim=1 按列**」——方向对，但不够用。
> 更准确的说法：**`dim=k` 表示往第 k 维的方向接长**。二维时 `dim=0` 就是往下接（行数变多），`dim=1` 就是往右接（列数变多）。

## 五、广播机制（修正一处误解）

我原来的速记写的是「广播指两个不一样的向量相加时自动维度补齐**补 0**」——**这里有个关键错误**：

> **广播补的不是 0，是「复制（拉伸）」**。补 0 会改变数值结果，广播不会。

```python
a = torch.arange(3).reshape((3, 1))   # [[0], [1], [2]]
b = torch.arange(2).reshape((1, 2))   # [[0, 1]]

a + b
# tensor([[0, 1],
#         [1, 2],
#         [2, 3]])
```

`a` 的列被**复制**成 `[0,0], [1,1], [2,2]`，`b` 的行被**复制**成 `[0,1]` 三份，然后逐元素相加。

**广播规则（两条）**：

1. 从**最后一维**开始往前对齐
2. 每一维要么相等，要么其中一个是 1（这一维被拉伸成对方的大小）

| 形状 A | 形状 B | 能否广播 | 结果 |
|---|---|:-:|---|
| (3, 4) | (4,) | ✅ | (3, 4) |
| (3, 1) | (1, 2) | ✅ | (3, 2) |
| (3, 4) | (3, 1) | ✅ | (3, 4) |
| (3, 4) | (2, 4) | ❌ | 3 vs 2 既不相等也不是 1 |

**实际用途**：`W @ x + b` 里，`b` 是 `(n,)`，会自动广播到每一行——这就是为什么偏置可以只写一个向量。

## 六、原地操作与 `id()`

```python
Z = torch.zeros_like(Y)
print(id(Z))       # 地址 A
Z[:] = X + Y
print(id(Z))       # 还是地址 A  ← 原地写入，地址不变
```

| 写法 | 地址变吗 | 原因 |
|---|:-:|---|
| `Z = X + Y` | ✅ 变 | 变量重新绑定到新张量 |
| `Z[:] = X + Y` | ❌ 不变 | 切片赋值 → `__setitem__`，写进原内存 |
| `Z.add_(Y)` | ❌ 不变 | 方法名带 `_` |

**我原来的速记**：「id 类似指针，每次赋新值地址改变」——**方向对了，但要说清「赋新值」和「原地写」的区别**：

- `Z = ...` 改的是**变量指向谁**（换指针）
- `Z[:] = ...` 改的是**指针指向的那块内存里的内容**（不换指针）

**`[:]` 本身不是原地标志**——它只是「取全部元素」。是否原地取决于它在等号哪边：

```python
W = Z[:]        # 只是取出内容，不是原地操作
Z[:] = X + Y    # 这里是原地（等号左边）
```

> **注意**：`Z[:] = X + Y` 中间那个临时张量 `X+Y` **还是被创建了**。它省的是「Z 的重复分配」，不是「完全不产生临时内存」。

## 七、踩的坑（汇总）

| 坑 | 报错 | 原因 | 解决 |
|---|---|---|---|
| `reshape` 形状不匹配 | `shape '[2, 4]' is invalid for input of size 12` | 各维乘积 ≠ 元素总数 | 让乘积对上（12 → 3×4） |
| `cat` 维度不匹配 | `Sizes of tensors must match except in dimension 0` | 非拼接维不相等 | 让其余维度一致 |
| 以为广播「补 0」 | 结果数值不对 | 广播是**复制**不是补 0 | 记住是拉伸 |
| 误以为 `[:]` 就等于原地 | — | `[:]` 只是切片 | 看它在等号哪边 |
