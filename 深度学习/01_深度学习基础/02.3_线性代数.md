# 2.3 线性代数

**一句话**：深度学习的所有运算，本质都是矩阵乘法。这一节建立「维度对齐」的直觉。

---

## 一、四个基本对象

| 名称 | 维度 | 例子 | 用途 |
|---|:-:|---|---|
| **标量** | 0 维 | `torch.tensor(3.0)` | 损失值、学习率 |
| **向量** | 1 维 | `torch.arange(4)` | 一个样本的特征、偏置 |
| **矩阵** | 2 维 | `torch.arange(20).reshape(5, 4)` | 一批样本、权重 |
| **张量** | n 维 | `torch.arange(24).reshape(2,3,4)` | 图像的 (通道, 高, 宽) |

**形状写在括号里**：`(3,)` 是一维长度 3，`(3, 1)` 是二维 3 行 1 列。**这两个不是一回事**——它们的形状不同，广播行为也不同。

---

## 二、按元素运算

```python
A + B        # 逐元素加
A * B        # 逐元素乘（不是矩阵乘法！）
A ** 2
torch.exp(A)
```

**矩阵乘法的符号是 `@`，不是 `*`**：

```python
A * B        # 逐元素，形状必须兼容广播
A @ B        # 矩阵乘法，形状要满足 (m,k) @ (k,n) → (m,n)
```

> 这是新手最容易踩的坑之一。`*` 只是逐元素，**不会求和**。

---

## 三、降维：`sum` 与 `axis`（重点）

**`sum(axis=k)` 就是把第 k 个维度「压扁」相加，结果里那个维度消失。**

### 2D 例子

```python
A = torch.tensor([[1, 2, 3],
                  [4, 5, 6]])   # 形状 (2, 3)
```

`A.sum(axis=0)` —— 沿第 0 维压，**每列竖着加**：

```
  1  2  3
  4  5  6
  ↓  ↓  ↓
  5  7  9
```

```python
A.sum(axis=0)     # tensor([5, 7, 9])   形状 (3,)   ← 行没了
A.sum(axis=1)     # tensor([6, 15])     形状 (2,)   ← 列没了
```

| axis | 方向 | 消掉谁 |
|:-:|---|---|
| `axis=0` | 从上往下压 | 行 |
| `axis=1` | 从左往右压 | 列 |

### 3D 例子

```python
X = torch.arange(24).reshape(2, 3, 4)   # 形状 (2, 3, 4)
```

拆成两层 3×4 的表：

```
第 0 层                        第 1 层
 0   1   2   3                 12  13  14  15
 4   5   6   7                 16  17  18  19
 8   9  10  11                 20  21  22  23
```

**贴个语义：2 个班级 × 3 名学生 × 4 门课**

| 写法 | 在图上 | 每个数怎么来 | 结果形状 |
|---|---|---|---|
| `sum(axis=0)` | 层与层之间 | 两层对应位置相加 | `(3, 4)` |
| `sum(axis=1)` | 每层内竖直方向 | 一列里 3 个数相加 | `(2, 4)` |
| `sum(axis=2)` | 每层内水平方向 | 一行里 4 个数相加 | `(2, 3)` |

对应语义：`axis=0` 两班合并；`axis=1` 学生合并（单科总分）；`axis=2` 课目合并（个人总分）。

`X.sum(axis=2)` 的值：

```python
tensor([[ 6, 22, 38],
        [54, 70, 86]])
```

### 唯一需要记的规律

> **`sum(axis=k)` 的结果形状 = 原形状删掉第 k 位。**

| 写法 | 结果形状 |
|---|---|
| `X.sum(axis=0)` | `(3, 4)` |
| `X.sum(axis=1)` | `(2, 4)` |
| `X.sum(axis=2)` | `(2, 3)` |

### 必须记住的坑

**`axis=0` 消掉的是「最外面那一层」，不是「上面那一行」。**

2D 时 `axis=0` 消掉行，容易误以为「`axis=0` = 行方向」；到 3D，`axis=0` 消掉的是**层**。

> **别记「axis=0 是行」，要记「axis=0 是第 0 位」。按位置数，永远不会错。**

`axis=-1` 表示最后一维（3D 里等价于 `axis=2`），**深度学习里非常常见**——经常要对最后一维（特征、类别概率）求和。

### `keepdims=True`

```python
A.sum(axis=1)                        # tensor([6, 15])        形状 (2,)
A.sum(axis=1, keepdims=True)         # tensor([[6], [15]])    形状 (2, 1)
```

| 写法 | 形状 | 说明 |
|---|---|---|
| 默认 | `(2,)` | 维度被删掉 |
| `keepdims=True` | `(2, 1)` | 维度保留，缩成 1 |

**用途**：做归一化时必须用它才能正确广播。

```python
A / A.sum(axis=1, keepdims=True)   # (2,3) / (2,1) 可广播，每行之和 = 1
```

> 如果不加 `keepdims`，`(2,3) / (2,)` 会对齐到错误的维度上，**结果悄悄错掉，却不报错**。这类 bug 最难查。

## 四、点积、矩阵乘法、范数

```python
torch.dot(x, y)      # 点积：同长度向量 → 标量（逐元素相乘再求和）
torch.mv(A, x)       # 矩阵 × 向量：(m,n) @ (n,) → (m,)
torch.mm(A, B)       # 矩阵 × 矩阵：(m,k) @ (k,n) → (m,n)
A @ B                # 同上，更常用
torch.norm(x)        # L2 范数：向量长度
```

**记忆方式**：矩阵乘法的形状规律是「**中间的维度要相同，然后被吃掉**」：

```
(m, k) @ (k, n) → (m, n)
        ↑↑
     这一对必须相等，乘积完后消失
```

**范数的直观**：`torch.norm(x)` 就是向量在空间里的**长度**。常见用途是衡量「模型参数有多大」（权重衰减、梯度裁剪）。

## 五、和广播的联系

线性代数运算和 [[02.1_数据操作]] 里的广播机制是配合使用的：

```python
W @ x + b
#   ↑     ↑
# (m,n)@(n,) → (m,)   然后 (m,) + 标量 b，广播
```

**偏置 `b` 只是一个数或一个向量，却能加到所有行上**——这就是广播在做的事。
