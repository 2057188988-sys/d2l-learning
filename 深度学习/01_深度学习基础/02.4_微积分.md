# 2.4 微积分

**一句话**：梯度指向函数**增长最快**的方向。想让它变小，就往反方向走——这就是「梯度下降」，也是整个深度学习的引擎。

**这一节讲「梯度是什么、为什么有用」；下一节 [[02.5_自动微分]] 讲「怎么让计算机自动算出来」。**

---

## 一、先破除对 `∂y/∂x` 的恐惧

**`∂y/∂x` 没有做任何新运算，只是把一堆普通偏导数装进一个向量。**

假设 `y = x₁² + x₂² + x₃²`，`x = [1, 2, 3]`，则 `y = 1 + 4 + 9 = 14`。

```
∂y/∂x₁ = 2x₁ = 2      （只拧第 1 个旋钮）
∂y/∂x₂ = 2x₂ = 4      （只拧第 2 个旋钮）
∂y/∂x₃ = 2x₃ = 6      （只拧第 3 个旋钮）

∂y/∂x = [2, 4, 6]     ← 这就是「梯度」
```

**「偏」= 只看其中一个变量。** `∂y/∂xᵢ` 的含义：

> **把其他变量按住不动，只轻轻动一下 xᵢ，y 涨多快？**

单独看任何一个偏导数，都只是普通的一元导数——没有任何新东西。

---

## 二、梯度 = 偏导数排成队

```
∂y/∂x = [∂y/∂x₁, ∂y/∂x₂, ∂y/∂x₃]
```

**它没有做新运算，只是把已经会算的偏导数装进一个向量。** 这个向量叫**梯度**。

觉得抽象，是因为符号 `∂y/∂x` 让人以为「一个东西对整个向量求导」是个复杂操作；实际上它是「**逐个成员分别求导，再排成一队**」。

---

## 三、形状规律（唯一需要记的）

| 求谁 | 结果是什么 | 结果形状 |
|---|---|---|
| 标量 → 标量 | 一个数 | 标量 |
| **标量 → 向量** | **向量** | **与 x 同形** |
| 标量 → 矩阵 | 矩阵 | 与 X 同形 |
| 向量 → 向量 | 矩阵（雅可比） | `(y的维度, x的维度)` |

**最常用的规律**：**标量对向量求导，结果形状 = 那个向量的形状。**

原因很简单：每个分量对应一个偏导数。

---

## 四、为什么书上的形状对不上（(4,) vs (4,1)）

d2l 书里写的是：

```
∂y/∂x = [∂y/∂x₁, ..., ∂y/∂x₄]ᵀ     形状 (4, 1)
```

而 PyTorch 里：

```python
x = torch.arange(4.0, requires_grad=True)
y = 2 * torch.dot(x, x)      # = 2(x₁²+x₂²+x₃²+x₄²)
y.backward()
print(x.grad)                # tensor([0., 4., 8., 12.])   形状 (4,)
```

**是 `(4,)` 不是 `(4,1)`。**

**这个差异纯属记号约定**：数学书写列向量是为了矩阵乘法对齐，PyTorch 的一维张量不区分行列。

> **看到 `ᵀ` 不用慌，那只是「摆正姿势」，不影响数值。** 只需要关心「哪几个数、按什么顺序排」。

## 五、亲手验证

```python
import torch

x = torch.tensor([1.0, 2.0, 3.0], requires_grad=True)
y = (x ** 2).sum()          # y = 1 + 4 + 9 = 14
y.backward()

print(y.item())             # 14.0
print(x.grad)               # tensor([2., 4., 6.])   ← 与手算 2xᵢ 完全一致
```

改一个数，梯度立刻跟着变：

```python
x = torch.tensor([5.0, 2.0, 3.0], requires_grad=True)
((x ** 2).sum()).backward()
print(x.grad)               # tensor([10., 4., 6.])  ← 2×5 = 10
```

**这种「能验证」的感觉，比盯着公式推导有用得多。**

## 六、梯度的真正用途

```python
w = w - lr * w.grad      # 往梯度反方向走一小步，损失下降
```

| 符号 | 含义 |
|---|---|
| `w` | 要训练的参数 |
| `w.grad` | 损失对 w 的梯度 |
| `lr` | 学习率（每次走多远） |
| `-` | 往**反**方向走 |

**为什么是反方向**：梯度指向 y 增长最快的方向。想让 y 变小，就往反方向走。

**这解释了「形状为什么必须一致」**：要做 `x = x - lr * grad` 这个减法，两者必须**逐元素对应**。

> **形状规律不是数学家的洁癖，是被「参数更新」这个用途逼出来的。**

---

## 七、链式法则（一层套一层）

如果 `y = f(u)` 而 `u = g(x)`，那么：

```
dy/dx = (dy/du) · (du/dx)
```

**「外面一层导数 × 里面一层导数」**。多层网络就是这样一层层乘上去的——这就是**反向传播**的全部原理。

举个具体的：`y = (2x + 1)²`

```
设 u = 2x + 1，则 y = u²
dy/du = 2u = 2(2x+1)
du/dx = 2
dy/dx = 2(2x+1) · 2 = 8x + 4
```

## 八、放下心理包袱

**在深度学习实践中，你几乎永远不会手算矩阵求导。**

| 你会做的 | 你不会做的 |
|---|---|
| 知道梯度 = 偏导数排成队 | 手推 `∂y/∂X` 的展开式 |
| 知道结果形状和谁一致 | 背矩阵求导的十条法则 |
| 会用 `.backward()` 和 `.grad` | 求雅可比矩阵的每个元素 |
| 会用链式法则连乘 | 手算多层复合的导数 |

李沐讲矩阵求导，是为了让你**看得懂论文里的公式**（论文里到处是 `∂L/∂W`），不是要你手算。下一节就会把这一切交给 `backward()`。

**目标**：看到 `∂y/∂x` 能翻译成「对 x 的每个分量分别求偏导，排成向量」，就够了。
