# 02 预备知识

**地位**：整本书的**语言课**。后面每一章都在用这里的东西，但这里几乎不讲深度学习。

> **别跳过这一章。** 很多人急着看 CNN/Transformer，结果卡在「这个张量形状怎么来的」「loss.backward() 到底做了什么」。根源都在这一章。

---

## 这一章给你四把工具

| 节 | 工具 | 解决什么问题 | 笔记 |
|:-:|---|---|---|
| 2.1 | **张量操作** | 数据怎么装、怎么变形、怎么拼 | [[02.1_数据操作]] |
| 2.2 | **线性代数** | 向量/矩阵运算、维度对齐 | [[02.2_线性代数]] |
| 2.3 | **微积分** | 梯度从哪来、为什么能降 loss | [[02.3_微积分]] |
| 2.4 | **自动微分** | 不用手算梯度，框架怎么做到 | [[02.4_自动微分]] |
| 2.5 | **概率** | 处理不确定性、损失函数为什么长这样 | [[02.5_概率]] |

**它们的关系**：

```
2.1 张量  ──→  数据用张量装
2.2 线代  ──→  张量按矩阵规则运算
2.3 微积分 ──→  算出梯度（手算的思路）
2.4 自动微分 ──→  让框架自动算梯度（真正的做法）
2.5 概率  ──→  损失函数、采样、评估的理论来源
```

**2.3 和 2.4 的关系要理清**：2.3 讲「梯度是什么、为什么有用」，2.4 讲「怎么让计算机自动算出来」。**理解了 2.3，2.4 就只是工具；跳过 2.3，2.4 就变成魔法。**
