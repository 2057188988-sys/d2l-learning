# NLP 学习路线 · 影视文本 → CCF-C

> **目标**：年底（12 月底）具备「正式产出」能力——能跑通一个影视文本 NLP 基准模型、会换/改模块、定好选题。次年 1 月起进入裁缝阶段（消融 + 对比实验 + 写论文），研二上投 CCF-C。
>
> **时间预算**：每天 1–2h。全程用**区间制**：
> - **最低** = 再忙也保底的量（每天 1h 就够，出差/满课也不断线）
> - **最高** = 状态好时的目标（每天 2h）
> 在一周内于两者之间徘徊即可，**不要死磕最高，掉到最低也不算失败**。
>
> **配合 AI 的方式**：AI（Trae）负责「筛选路线 / 逐行讲代码 / 总结论文 / 生成骨架」；你负责「动手跑 + 写笔记」。看 ≤ 1/3 时间，跑代码 + 写笔记 ≥ 2/3。

## 一、裁剪原则（先砍，再学）

只保留 NLP 对口内容，其余整块砍掉——**时间紧张时，「不学什么」比「学什么」更重要**。

| 砍掉 | 原因 |
|---|---|
| 李沐 6/7 章 CNN、13 章 CV | 非本课题主线，除非涉及视频-文本多模态 |
| 李沐 12 章计算性能、16 章工具 | 多卡训练 / 云平台，用不上 |
| 第 11 章除「Adam + 学习率调度」外 | 调参够用即可，不啃凸优化推导 |
| 循环网络的深水区推导 | 只需「序列建模」直觉 |
| 一切「先收藏后学」的网课、注意力变体花式实现 | 收藏 ≠ 学会，直接上代码 |
| 从零预训练大模型 | 算力陷阱，一律用 HuggingFace 现成权重 |

## 五、每周固定动作（配 AI 走）

1. **学**：只看本周主题的一个概念，不刷视频。
2. **跑**：把概念写成能跑的代码，跑通并看到结果。
3. **问 AI**：让它用「大白话 → 逐行映射回代码」的方式讲一遍。
4. **记**：按 [[笔记规范]] 写 5 行（学了什么 / 写了什么 / 报了什么错 / 怎么定位 / 这跟影视文本有什么关系）。
5. **勾**：回到 [[学习计划]] 更新状态；周末对着本表勾掉「最低/最高」打到哪。
